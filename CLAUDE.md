# Studies Hub (studieshub.org)

This repository is the source of the studieshub.org website. The owner gives instructions in chat; Claude writes the code and pushes it straight to `main` in this repo.

## Working rules
- Build only what the owner asks for. Keep changes small and focused.
- Before pushing a large or risky change (deleting files, changing login, payments, or anything that could take the site down), say what will change and wait for a yes.
- Never commit secrets. Keys and passwords go in `.env` (ignored by git) or the host's environment settings.
- After every push, tell the owner what changed and which files were touched.
- Keep the code simple enough that the owner can understand and maintain it.
